# 学术首页视觉规范

## 模式与约束

- 模式：Redesign Overhaul，仅重构首页视觉和信息层级。
- 保留：数据接口、认证、上传权限、图表交互、锚点、四个分析工具正式路径。
- 首页已经是默认正式界面；`/ui-home-academic` 仅保留为历史链接兼容入口。

## Design Read

- 受众：污水流行病学研究者、疾控人员、数据维护人员。
- 视觉语言：纯白学术编辑风，强调证据、空间和方法的可追溯性。
- Visual variance：5，采用 Swiss 式信息网格和一行四列的紧凑工具入口。
- Motion intensity：4，使用短时进入、悬停反馈、词云低速运动与少量证据节点呼吸漂移。
- Information density：6，首屏后优先展示四个工具入口，再进入证据总览。
- Asset dependence：7，首屏与工具入口共用无文字科研线稿，模块使用同源科研概念插画。
- Brand fidelity：7，以自有证据路径标志增强识别，保留数据库命名和全部业务契约。

## 设计系统

- 页面背景：`#ffffff`，纯白。
- 主要文字：`#0b1f33`，深海军蓝。
- 次要文字：`#56697a`。
- 主色：`#1263a8`，研究蓝。
- 辅助色：`#33a18e`，仅用于品牌数据点与科研插画。
- 分隔线：`#d7e0e6`。
- 字体：`Helvetica Neue / PingFang SC / Noto Sans SC / Microsoft YaHei` 系统无衬线栈，数字使用等宽数字特性。
- 间距：8px 基础单位，页面容器最大宽度 1440px。
- 圆角：按钮 9 至 10px，信息表面 12px，数据区域以直角分隔线为主。
- 阴影：仅用于导航下拉和弹层，主体内容不依赖阴影建立层级。
- 动效：`cubic-bezier(.22, 1, .36, 1)`；进入 480-600ms，交互反馈 160-240ms。

## 资源

- 品牌标志：`src/components/BrandMark.vue`，由 W 形证据路径与四个数据节点组成，对应空间、关联、优先级和方法核验。
- 产品动图：`public/academic-home/gifs/`，鼠标或键盘聚焦对应板块时播放。
- 静态封面：`public/academic-home/posters/`，用于动图未加载和减少动效模式。
- 真实界面源图：`public/academic-home/screens/`，仅保留生成当前三组动图和使用说明所需的截图。

## 禁止项

- 不使用紫色渐变、霓虹、玻璃拟态、滚动劫持和鼠标跟随。
- 不虚构统计数字、机构、团队、成果或界面。
- 不在首屏使用实际产品截图或虚构界面。
- 四个分析入口在桌面端使用一行四列，整个入口都是可访问链接，不再设置重复的“进入分析”按钮。
- 工具入口默认不显示下划线，仅在悬停、键盘聚焦或按下时为标题增加研究蓝下划线。
